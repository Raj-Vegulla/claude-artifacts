Safety Rails

What we're not touching automatically

699 records are excluded from automatic cleanup even though they fall in Tiers B/C. These require human review because deletion could impact live IDX access.

451 Sole Auth
Only active authorization for this company on this MLS feed. Deleting would kill IDX / home search for that entire board. Must verify the company doesn't need this feed first.
124 Cross-Company

MLS ID is valid on a different MLS board for the same company. These are reconnect candidates, not deletions — auth needs to point to the correct feed.
Approach

Soft delete with full backup

Per Daniel and Frank (confirmed April 14) — the table supports soft delete via a deleted_at timestamp column. No rows are permanently removed.

🛡️ Cleanup Method
All deletion tickets use UPDATE instead of DELETE:
UPDATE identity.mls_authorization
SET deleted_at = NOW(),
    status = 'DELETED'
WHERE id IN (...);
🔄 Rollback
Any record can be restored instantly by undoing the soft delete:
UPDATE identity.mls_authorization
SET deleted_at = NULL,
    status = 'ACTIVE'
WHERE company_id = ...;
Backup table created regardless data_monitoring.mls_authorization_cleanup_backup_20260414 — full snapshot of all 4,453 in-scope records before any changes are made.
